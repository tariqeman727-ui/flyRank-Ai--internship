Content Refresh Prioritization

FlyRank Machine Learning Capstone

Eman Tariq

Research Question

Can search performance metrics such as clicks, impressions, CTR, and average position be used to identify webpages that should be prioritized for content refresh?

The project supports content teams in identifying webpages that may benefit from content updates and prioritizing their work.

Dataset

Dataset: FlyRank ML Internship Dataset
Time Window: March 2026
Unit of Analysis: One webpage (URL) in one month

Main Features:

  • Clicks
  • Impressions
  • CTR
  • Average Position

Methodology

The project followed an ML workflow including problem framing, data analysis, feature and leakage checks, baseline construction, model training, validation, and action recommendations.

A Decision Tree model was used because it provides an interpretable approach for identifying patterns in search performance signals.

Label-derived and future information was excluded to reduce leakage risk.

Baseline vs Model

Approach Method Evaluation
Week 4 Baseline Rule-based prioritization using search/content performance signals. Same validation setup
Decision Tree Model ML-based prioritization using search performance features. 80% training / 20% testing

The baseline and model were compared using the same evaluation setup to support a fair comparison.

Key Findings

  • Pages with high impressions but low CTR may represent content optimization opportunities.
  • Average position provides useful ranking context for prioritization.
  • Search performance signals can support structured content refresh decisions.
  • The results are directional and should be treated as decision-support evidence.

Ranked Recommendations

  1. Refresh pages with high impressions but low CTR.
  2. Update outdated content that shows declining performance.
  3. Improve titles and meta descriptions to increase click opportunities.
  4. Review keyword alignment and user intent.
  5. Monitor performance and retrain the approach when new data becomes available.

Human Review & Limitations

Recommendations should be reviewed by a human before content changes are made.

  • The model does not guarantee improved rankings.
  • The model does not predict Google's search algorithm.
  • Results depend on the available dataset.
  • Additional content-quality signals could improve future work.
  • The project was evaluated on internship data, not production data.
